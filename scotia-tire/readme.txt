A dark, high-contrast WooCommerce theme for Scotia Tire & Alignment — commercial, fleet, and trailer tire services in the GTA.

== Description ==

Built from the Scotia Tire & Alignment pricing-sheet brand: black chassis, red accents,
bold italic headings. Full WooCommerce support including styled product grids, single
product pages, cart, checkout, and My Account.

Features:

* Front-page hero card with "Best Value" badge (Full 3-Axle Alignment)
* Services grid — automatically shows your featured (or latest) WooCommerce products,
  with a static pricing-sheet fallback until products exist
* Feature strip: Hunter 3D Equipment, Certified Technicians, GTA-Wide Coverage, 24/7
* Sticky header with cart count that live-updates via AJAX fragments
* Customizer panel ("Business Details") for phone, address, hours, brand sub-line,
  and footer fine print
* Custom logo support (falls back to the tire-wheel brand mark)
* Three footer widget areas + footer menu
* Responsive with mobile menu toggle
* Translation-ready (text domain: scotia-tire)

== Installation ==

1. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme.
2. Choose scotia-tire.zip and click Install Now, then Activate.
3. (Optional) Install and activate WooCommerce, then add your services as products —
   mark up to four as "featured" to pin them on the front page.
4. Set a static front page (Settings > Reading) or simply keep the theme's built-in
   front-page layout, which renders automatically on the site front page.
5. Configure business details under Appearance > Customize > Business Details.
