The 28-Room Build Sheet

Everything on this sheet is either open source you can audit or legal logic we author ourselves — nothing in the load-bearing path is a black box you rent. The doctrine is simple: adopt the plumbing, build the law. No open-source project knows what a limitation period is. Every one of them knows how to store a file, run a workflow, or serve a model.

Laid out A to Z: the ground rules, the eleven layers of the stack, what each of the 28 rooms adopts and what it builds, the matter file underneath them all, how a filing moves through the machine, the repository itself, and — honestly — where open source runs out.

01

Ground rules

Four decisions made once, before any code, so nobody has to re-make them under deadline pressure.

Rule 1

Adopt the plumbing, build the law

The differentiated asset is rules-as-code, the citation gate, and the trust ledger — the legal logic. Storage, search, OCR, workflows, editors, inference: all commodity, all adopted. If a build-vs-adopt call is close, adopt; if the thing encodes a rule of law or professional conduct, build it and test it like the malpractice policy depends on it.

Rule 2

Licence policy, decided once

Permissive (Apache-2.0, MIT, BSD, MPL) links anywhere, including in-process. AGPL is welcome as a self-hosted, network-isolated service we don't modify — MinIO, OnlyOffice, Grafana, Documenso. Relicensed ex-OSS gets its community fork: OpenTofu for Terraform, OpenBao for Vault, Valkey for Redis, GlitchTip for Sentry. Nothing BSL or fair-code in the core.

Rule 3

One system of record, one wall

PostgreSQL holds everything — matters, facts, deadlines, the ledger, and the vectors. The ethical wall is enforced twice, independently: row-level security at the database and OpenFGA at the application, and both must agree. Because embeddings live in the same rows, retrieval cannot leak what the wall hides. There is no second store to forget to secure.

Rule 4

Boring by default

A modular monolith — one API service, one module per room — plus exactly three heavy services split out from day one because they scale differently: the document pipeline, model inference, and citation verification. Temporal owns anything long-running. No further microservice until a measured scaling fact forces one.

04

The matter file

The shared kernel every room reads and writes — seventeen entities in Postgres. Every row carries tenant_id, matter_id and the wall context for RLS; audited tables add a hash-chain pointer. Rooms own their private tables, but cross-room truth lives only here.

matter

  • jurisdiction_lock — court, division, governing law
  • posture · theory · budget ceiling
  • wall_id · privilege class · status
The root aggregate. Room 01 creates it; everything else references it.

person_org

  • canonical_id · names[] · aliases
  • splink_cluster — resolved entity
  • corporate parents / subsidiaries
One identity across every matter — the conflicts graph's nodes.

party

  • matter · person_org · role
  • adverse? · represented_by
  • added_at — triggers conflict re-check

wall

  • members · screened[] · basis
  • mirrored to OpenFGA tuples
  • attestation log

document

  • blob_hash (BLAKE3) · source · custodian
  • privilege state · Bates range
  • ocr/extraction status

doc_version

  • document · editor · diff
  • provenance — drafted / edited / authored
  • hash → audit chain
The record shown when someone asks what the machine wrote.

fact

  • date · actor · text
  • source_pin — doc, page, line
  • disputed? · issues[]
No source pin, no row — enforced by constraint, not review.

authority

  • cite (eyecite-normalised) · court · date
  • treatment · verified_at
  • corpus pointer (CAP / CourtListener)

citation_instance

  • doc_version · authority · pinpoint
  • quote_match? · proposition_ok?
  • status — verified / blocked
The gate's working table: one row per cite per draft.

deadline

  • trigger_event · rule_ref · computed_date
  • chain — recompute cascade
  • Temporal timer id · escalation

task

  • room · assignee · due · state
  • blocking? · linked deadline

exhibit

  • document · number · list
  • foundation — witness, rule, hearsay path
  • offered / admitted state

undertaking

  • examination · text · owed_by
  • due · answered_at
Canadian discovery runs on these.

time_entry

  • timekeeper · utbms · narrative
  • state — draft / pre-billed / billed
  • pre-bill lint flags

ledger_entry

  • account (trust | operating) · dr/cr
  • immutable · reversal_of
  • reconciliation batch
Append-only. The schema itself refuses commingling.

filing

  • court · packet_hash · signed_by
  • filed_at · confirmation
  • service records

audit_event

  • actor · action · object
  • prev_hash · hash — BLAKE3 chain
  • anchored daily to WORM storage

How a filing moves

The whole machine in one pass — from a banker's box of scans to a stamped filing — with the tool doing the work at each step. Steps 08 and 09 are the gates: they block, they do not warn.

01

Ingest

Upload or email-in. Blob hashed and stored content-addressed; type sniffed; the matter's event stream announces it.

MinIO · BLAKE3 · Tika · NATS
02

Extract

Text and metadata out of any format; scans OCR'd into searchable PDFs; layout-aware chunking for downstream use.

Tika · OCRmyPDF + Tesseract · unstructured
03

Resolve & tag

People and dates recognised, PII flagged, parties linked to canonical entities — which silently re-runs the conflicts check.

spaCy · Presidio · Splink
04

Index

Full-text into the review index; embeddings into Postgres, inside the wall's row policies.

OpenSearch · BGE-M3 → pgvector
05

Capture facts

A reviewer promotes passages to Facts, each pinned to its page and line. The Chronology grows; gaps surface.

Room 06 · PDF.js anchors
06

Draft

The brief assembles in the structured editor — facts and authorities as live nodes; form documents run through interviews and templates.

TipTap + Yjs · docassemble · docxtpl
07

Adversary pass

The Moot Room writes the other side's best response and pins its objections to the paragraphs they attack.

Room 19 · vLLM
08

Verify — gate

Every cite parsed, resolved against the corpus, quote and pinpoint matched, treatment checked. One unresolved cite blocks the document.

eyecite · CourtListener / CAP · Room 08
09

Ethics pass — gate

Conflicts re-confirmed against the current party graph; required disclosures (including AI-use certifications) attached.

Room 02 · OpenFGA
10

Format

Court stylesheet applied — caption, line numbers, tables, exhibit tabs — identifiers redacted, redactions QC'd, packet assembled.

Typst / WeasyPrint · Gotenberg · pikepdf · X-Ray
11

Sign

The attorney of record reviews and signs. Provenance — drafted, edited, authored, by whom — seals into the audit chain. Nothing transmits before this.

Documenso · audit chain
12

File & ripple

Packet out to the portal (a human files where no API exists), confirmation ingested back, the deadline cascade recomputes, and the fee lands in the books.

07

Where open source runs out

The honest section, in the accuracy-doctrine spirit: six places nothing on a repo shelf solves, with the plan for each. Budget these like the product they are — because they are.

Gap 1

Court rules content

The deadline engine is open source all the way down — but the rules data for every court must be authored, versioned, and maintained by people who read amendments for a living. This is the largest ongoing cost on the sheet and the deepest moat. Treat the rules packages as a data product with editors, review, and effective-dating.

Gap 2

Citator treatment

There is no open Shepard's. Day one, Citation Check verifies existence, quote, and pinpoint against the open corpora — already ahead of the sanctions cases. Treatment flags come next: the CourtListener citation graph plus a negative-treatment classifier, with every flag through a human verification queue before it blocks or clears anything.

Gap 3

E-filing APIs

CM/ECF has no public write API, and most state and provincial portals are commercial gateways. The Filing Room therefore perfects the packet and a human files it; confirmations and stamped copies are ingested back automatically. Where a real API exists, it's an adapter behind the same room — the workflow never changes shape.

Gap 4

Canadian case law

CanLII's terms restrict bulk and commercial use — its licence is a business negotiation, not a scraper. Statutes are fine: federal and provincial consolidations ship under open licences. Plan the Canadian authority corpus around negotiated access plus the open primary sources.

Gap 5

Verdict & settlement data

Comparable-outcome data is mostly commercial. Case Value starts from public awards databases and the firm's own closed matters, and its bands widen honestly where data is thin — a wide honest band beats a narrow invented one, per the accuracy doctrine.

Gap 6

Moving money

Card and ACH acquiring is regulated processor territory; no open-source project does it and none should. The boundary is drawn so the processor only moves money while our ledger decides what is permitted to move — trust rules enforced on our side of the line, always.
